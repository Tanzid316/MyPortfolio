Featured Project

MetaShift

MetaShift is a 2D arcade-style side-scrolling action game developed using the iGraphics library in C. The game focuses on vehicle evolution, terrain-based movement, and strategic resource management.

Players need to balance coins and fuel to progress through different levels. The game includes shooting mechanics, enemy challenges, and final transformation into a combat mech.

Role: Developer

Genre: 2D Arcade Action

Key Focus: Game logic, resource management, level progression

Language: C, C++

Library: iGraphics

IDE: Visual Studio 2013

Platform: Windows PC

  • Four level-based progression system with increasing difficulty.
  • Vehicle evolution system with new abilities in each level.
  • Different enemy types requiring different combat methods.
  • Coin and fuel-based resource management system.
  • Shooting mechanics and final combat transformation.
